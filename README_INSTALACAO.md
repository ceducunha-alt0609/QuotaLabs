# QuotaLab PWA — Instalável no PC e Mobile

Este pacote está pronto para GitHub Pages.

## Arquivos principais
- index.html
- manifest.json
- manifest.webmanifest
- sw.js
- favicon.ico
- /icons
- /splashes

## Como instalar no PC
1. Suba todos os arquivos para o GitHub Pages.
2. Abra o site no Chrome ou Edge.
3. Clique no botão “Instalar app” do navegador ou no botão de instalação do QuotaLab, quando aparecer.
4. O app abre em janela própria, como aplicativo.

## Como instalar no Android
1. Abra o site no Chrome.
2. Toque em “Instalar app” ou “Adicionar à tela inicial”.
3. O ícone Monograma Q será criado na tela inicial.

## Como instalar no iPhone/iPad
1. Abra o site no Safari.
2. Toque em Compartilhar.
3. Escolha “Adicionar à Tela de Início”.
4. O ícone Monograma Q será criado na tela inicial.

Observação: iOS não exibe o mesmo botão automático de instalação do Android/Chrome; o padrão da Apple é pelo menu Compartilhar.
